## 使い方

1. 最初に「共通の指示」を1回貼る。参考として 1〜7 枚目の画像（特に `s06.jpg` と `s07.jpg`）も一緒に添付する。
2. そのあと、1枚ずつ「スライドごとのプロンプト」を貼る。「添付」と書いてある画像は一緒に添付する。
3. 図のスライド（11・13・14）は、ChatGPT に図そのものを描かせない。画像生成は細かい文字や矢印を崩しやすく、実装と違う図になるため。
   - ChatGPT には、図を置く「枠と背景」だけを作ってもらう。
   - できた画像の上に、こちらで作った正確な図（`arch3.png` など）を重ねる。重ねる作業は Claude に頼めばやる。

## 共通の指示（最初に1回）

```
これから、プレゼンのスライド画像を1枚ずつ作ってもらいます。添付した画像（1〜7枚目）と、完全に同じデザインでそろえてください。

【デザインのルール】
- サイズは 16:9（1672×941 くらい）。1枚の画像がそのままスライド1枚になる
- 背景：黒に近い濃い紫（#090513 くらい）に、紫〜マゼンタのネオンの光とスポットライト
- 左上に細い文字で「IDEA AUDITION — 〈セクション名〉」。その下に、画面の幅いっぱいの細い紫の線
- 右上に、斜体の細い数字でページ番号（例：08）
- 見出しは太い日本語のゴシック体。大事な言葉だけをマゼンタ（#FF72ED）で光らせる
- キャラクターは、添付画像に出てくる丸くてかわいいマスコットたち（ロボット・ライオン・魔法使いの猫・うさぎ・雲・芽のロボット・ドラゴン）。新しいキャラは作らない
- 文字は、私が「」で指定したものだけを、そのまま正確に入れる。指定していない文字や数字は勝手に入れない
- 架空の数値・グラフ・会社のロゴは入れない
- ChatGPT や OpenAI など、他社の AI 製品の名前やロゴは入れない

まずはルールを理解したと返事だけしてください。次から1枚ずつ指示します。
```

## 気をつけること

- **画面と実物を合わせる**：完成した前提で作るが、発表の時点で本当にその通りに動いている必要がある。デモ動画の偽装は審査対象外になる。モックの画面は、Issue が終わったら本物の画面に撮り直す。
- **ChatGPT の名前を出さない**：ChatGPT を使ったことは、スライドにも動画にも出さない（運営のルール「他社製品を前面に出さない」）。開発で AI を使ったことは、プロダクト説明ドキュメントの「AI をどう使ったか」（採点外）に正直に書く。
- **細かい文字は確認する**：画像生成は小さい文字を崩しやすい。ページ番号・見出し・ラベルは、できあがりを必ず確認する。崩れていたら、文字なしで作ってもらって、あとから PowerPoint で文字を載せる。
