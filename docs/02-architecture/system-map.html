IDEA AUDITION の全体図

今の本番（Cloud Run revision 00006）に、ADR-0009 の好みエンジン（好みの学習・🤝橋渡し案・「うーん」への反応・案の質・効果の指標）を入れたあとの姿です。黄色の NEW が今回追加する部分で、それ以外はすでに動いています。

会場（審査員のPC） Cloud Run のコンテナ Google Cloud のサービス Vertex AI（Gemini） 開発・チーム 好みエンジンで追加

サービス構成図 01 / SERVICE MAP

どのツールがどのツールと、何でつながっているか。点線は「毎回のやり取りではない」つながり（権限・監視・端末内の処理）です。

コンテナは1つ画面の配信、/hip、/voice、SessionActor が同じ Cloud Run の1台に入っています。最大1台・セッションアフィニティで、全員が同じメモリ上のセッションに入ります。
Gemini を呼ぶのはサーバーだけブラウザは鍵もトークンも持ちません。サービスアカウント idea-audition-run の権限で Vertex AI と Firestore を呼びます。
増えるのは2本の線だけ埋め込み（gemini-embedding-2）への呼び出しと、マイクから送る声の特徴です。外のサービスは増えません。

好みの更新taste ← taste·0.5^(Δt/90秒) ＋ 重み·案の8軸。決勝へのドラッグは強く、却下はマイナス、迷いは弱く効きます。
選抜案を必要数の約2倍作り、好みとの近さ（fit）・2人の間（bridge = min(fitA, fitB)）・目新しさを足して、MMR で似た案を外し、温度つきで抽選します。
落ちたときGemini が失敗したら固定データで続行。埋め込みが失敗したら 8軸だけでスコアをつけます。

HIP メッセージ 10 / PROTOCOL v1

すべて packages/protocol の Zod スキーマで検証します。Command と Event は Firestore に残り、Ephemeral（カーソルなど）は残しません。

種類向きメッセージ役割
hello / welcome双方向hello · welcome · access_denied参加・合言葉・現在の snapshot
Commandブラウザ → サーバーSTART_AUDITION · SET_AI_MODE · REQUEST_PROMOTION · NEXT_IDEA · REJECT_CANDIDATE · PIN_CLAIM · UNPIN_CLAIM · ASK_CANDIDATE · REQUEST_REFINEMENT · SUBMIT_UTTERANCE · START_CHAMPION_VOTE · CAST_VOTE · CLOSE_VOTE · RESOLVE_TIE · SELECT_CHAMPION · RESET_SESSION · REGENERATE_PROPOSAL状態を変える頼みごと。result で成否が返る
Signal NEWブラウザ → サーバーSOFT_SIGNAL迷い・沈黙・笑い・声量と、そのとき見ていたカード。返事なし・1人毎秒2件まで（ADR-0010）
protocol_error NEWサーバー → ブラウザUNSUPPORTED_VERSION · MALFORMED · UNKNOWN_TYPE · NOT_JOINED黙って捨てずに、相手が直せる情報を返す
Eventサーバー → 全員SESSION_STARTED · SESSION_RESET · JUDGE_JOINED · JUDGE_LEFT · HOST_CHANGED · CANDIDATE_SPAWNED · CANDIDATE_ARCHIVED · CANDIDATE_LEAVING · CANDIDATE_STAYED · CONSENSUS_UPDATED · PROPOSAL_UPDATED · AI_MODE_CHANGED · PROMOTION_CONFIRMED · FINALIST_REFINEMENT_STARTED · FINALIST_CRITIQUE_POSTED · FINALIST_VERSION_PUBLISHED · CANDIDATE_ANSWERED · JUDGE_UTTERANCE_RECEIVED · CHAMPION_VOTE_STARTED · VOTE_CAST · TIE_DETECTED · CHAMPION_SELECTED起きたこと＋snapshot 全体。画面は snapshot を置き換えるだけ
Event NEWサーバー → 全員TASTE_UPDATED · CANDIDATE_REACTED · CANDIDATE_REVISED好みレーダーの更新、🤔 の反応、別案への差し替え
Ephemeralブラウザ → 他の人CURSOR_MOVED · DRAG_PREVIEW · FOCUS_CHANGED · MIC_STATE_CHANGED保存しない一時的な共有。FOCUS_CHANGED は迷いの宛先探しにも使う

HIP とOSSへの道 15 / PROTOCOL & OSS NEW

HIP は TCP や WebSocket の仲間ではなく、その上に載るアプリケーション層のプロトコルです。WebSocket は「届ける」だけで、4人が同時に昇格したら誰が勝つか、返事の前に切れた操作をどうするか、遅れて返った AI の結果をどう扱うかは決めてくれません。そこを決めているのが HIP です（ADR-0010、docs/protocol/hip-v1.md）。
